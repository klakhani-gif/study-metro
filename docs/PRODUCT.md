# Study Metro — Product Definition

## Promise
Turn your syllabus into a journey.

## Core metaphor
- Network = semester / qualification
- Line = subject
- Station = topic
- Journey = focus session
- Interchange = cross-subject topic
- Terminal = exam / major goal
- Maintenance = revision
- Service status = study risk / due revision

## V1 core loop
Create/select station -> choose duration -> start journey -> train advances using real elapsed time -> arrive -> station completes -> journey is recorded -> network visibly changes.

## Free model
Core productivity remains usable for free. One restrained banner placement may appear outside Focus Mode.

## Premium model
Target launch price: 4.99 GEL/month.
- No ads
- Premium themes / train skins
- Advanced analytics
- Deeper customization and future planning tools

## Rewarded access
A free user may voluntarily watch one rewarded ad to receive 3 hours of Premium. Never force rewarded ads to begin or complete a focus session.
